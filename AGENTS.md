
# AGENTS.md

## Project
Project: Dao Den Long
Type: Third-person 3D game
Engine: Godot 4
Language: GDScript

## Development Rules

1. Read the current phase requirements before coding.
2. Follow the Test Contract exactly.
3. Do not invent undocumented requirements.
4. Separate game logic from rendering.
5. Keep the game logic compatible with headless execution.
6. Make small, focused changes.
7. Do not modify unrelated files.
8. Never fake test results or evidence.
9. Run relevant tests after every change.
10. Do not commit API keys or .env files.

## Verification

- Run the game normally.
- Run the headless test scenarios.
- Save actual outputs and screenshots.
- Report failed tests honestly.

## Git

- Use small, meaningful commits.
- Create phase tags at each checkpoint.
- Never rewrite history after phase tags.
